02优劣势

有优势，也要看清楚劣势

优势
  • 审美好，有质感，不套模板
  • 动效丰富，过渡自然
  • 分享方便，一个链接搞定
  • 可交互，可嵌入各种元素
  • 节省时间，AI 直接生成
劣势
  • 临时改稿麻烦，不如 PPT 点两下
  • 不适合严格的格式要求，如需要提交 .pptx 文件的场合

🎉 AI PPT
背景

AI PPT 的底层：一张网页

HTML
内容骨架

定义每一页有什么：标题、正文、图片、列表。相当于 PPT 里的占位符。

CSS
视觉样式

控制颜色、字体、间距、动效、排版。PPT 好不好看，全在这里决定。

JS
交互逻辑

控制翻页、动画触发、点击响应。让 PPT 从静态变成「活的」。

💡

三者合一打包成一个 .html 文件，浏览器打开就是你的 AI PPT。AI 能写代码，所以它能直接帮你生成整套视觉。

03分类

两种方式理解 AI PPT 的分类

维度 A · 内容类型
有图 vs 无图
纯图文
只有文字 + 排版，最简单，AI 一次出稿成功率高。
VS
含图处理
插图、截图、特殊元素，需要在逐字稿里标注清楚排版意图。
维度 B · 视觉来源
有模板 vs 无模板
有视觉模板
基于已有设计规范（颜色/字体/组件），AI 对齐执行。
VS
无模板发挥
只给主题和风格描述，让模型自由设计，结果更惊喜也更不可控。

04制作方法
Step
01
逐字稿 / 提纲
4 步中的第 1 步
1

标注页面划分

标注 01 页、02 页或新一页，用分隔符，AI 才能准确切页。

2

给每张图加说明

写清楚图片内容、几张合一页还是各占一页、有没有特殊排版要求。AI 理解图片才能合理排版。

3

导出含原图的 Markdown 压缩包

Notion 导出选 Markdown，生成含文本和所有原图的 .zip——这就是 Agent 的资源库。

04制作方法
Step
02
投喂 Agent
4 步中的第 2 步
1

说明目标和视觉规范 👆

告诉 Agent：PPT 的主题、受众、整体风格，以及颜色、字体、设计语言等视觉规范。这步决定生成质量的上限。

传入压缩包 + Prompt

Agent 输出完整 HTML，浏览器直接打开。绝大多数页面第一版就能用，不需要重新生成。

如何向 Agent 描述视觉规范？
方式 1 · Prompt
# 角色设定 你是一位拥有顶级审美的「高级视觉体验设计师」，精通瑞士排版风、极简主义与北欧风。请把我的逐字稿/大纲，转化为一个具有高级感的 16:9 Web PPT。 # 视觉规范 - 整体风格：高级感浅色系，低饱和饱满配色，参考苹果设计物料与欧美顶尖杂志（经济学人、纽约客） - 字体：高对比度衬线体（Serif）做主标题，几何无衬线体（Sans-Serif）做正文；利用极粗与极细的字重对比，打造 Editorial 级排版效果 - 导航：极致克制——屏幕角落小页码 + 底部细进度条，低透明度融入背景 - 排版：保留文案和结构关系，谨慎思考留白与分栏，不做额外结构设计 - 图片：主动读取原图比例，单图定制布局，多图设计错落不规则网格，裁切时注意人物头部完整
方式 2 · 截图 + 一句话

截图一张你喜欢的视觉风格（网页、PPT、海报均可），发给 Agent，然后说：

「我要做一个 16:9 的 Web PPT，视觉风格参考这张截图，请先确认你理解了这个风格再开始。」
