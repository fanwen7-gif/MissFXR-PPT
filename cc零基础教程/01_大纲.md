## 第1章：Claude Code 到底是什么？

### 1.1 什么是 Agent？
- **Agent = 大模型 + 工具**
  - 大模型负责「思考和决策」，工具负责「实际执行」
  - 「工具」指它能调用的具体能力：读写文件、执行命令、搜索网页……
  - 两者加在一起才叫 Agent
- 类比：大脑 + 双手——光有脑子没有手，什么也做不了
- 关键认知：它可以「主动执行操作」，不只是回答问题

### 1.2 Claude Code 在做什么？
- 本质：读写你电脑上的文件、执行终端命令
- 你的电脑文件系统就是它的工作台
- 理解这一点之后，你才能真正理解为什么它能帮你「编程」

## 第4章：怎么用好它？12个技巧让你少走弯路

排序逻辑：最常遇到 → 基础必学 → 习惯养成 → 进阶扩展

### 技巧1 出错了怎么办 · 看不懂报错？这样处理
- 看不懂报错信息怎么处理
- 如何让它自己 debug
- 什么时候该放弃重来、重新开始一段对话

### 技巧2 Token & 费用意识 · 为什么越聊越贵？怎么省钱？
- 为什么对话长了它会「变笨」（Context 窗口的概念）
- 如何控制成本、避免不必要的浪费

### 技巧3 语音输入 · 说比打快，减少表达摩擦
- 想法说出来比打字快得多，尤其是描述需求、解释背景的时候
- 推荐在提需求、描述问题时用语音
- 工具推荐：系统自带语音输入 / 第三方转写工具

### 技巧4 CLAUDE.md · 让它永远记住你是谁、在做什么
- 怎么让它「记住」你的项目背景
- 解决 Context 窗口遗忘问题
- 基础配置，影响每次对话质量

### 技巧5 Plan Mode · 动手之前，先让它想清楚
- 做之前先让它列计划，避免改错、走偏
- 每次动手前都要用

### 技巧6 权限 & 安全意识 · 它能做很多事，你要知道边界
- 它能做很多事，你需要知道边界在哪里
- 越早知道越好

### 技巧7 Git 管理代码 · 后悔药：每次大改前先存档
- 什么是 Git：给你的代码拍「快照」，随时可以回到之前的版本
- 为什么用 Claude Code 时尤其需要它：AI 改代码有时会改出问题，有 Git 就有后悔药
- 基本操作：commit（存档）、回滚（读档）
- 养成习惯：每次让它做一个大改动之前，先 commit 一次

### 技巧8 动手前先搜一搜 · 不要重复造轮子
- 想做的事情，先问它「有没有现成的工具 / 库 / 方案」
- 很多功能已经有人做好了，直接用
- 这个习惯能帮你省大量时间，也是真正的程序员思维

### 技巧9 MCP · 接入外部服务，让它连接你的世界
- 接入外部服务（比如让它读你的数据库、操控浏览器）
- 需要一定使用基础再碰

### 技巧10 Hook · 设定触发条件，让它自动运行
- 自动触发动作
- 进阶，用了一段时间才有需求

### 技巧11 Skill & Tool · 扩展它的能力边界
- 扩展能力边界
- 进阶定制化

### 技巧12 插件生态 · 现成的工具，直接用
- 了解有哪些现成工具可以直接用
- 了解生态，最后探索
