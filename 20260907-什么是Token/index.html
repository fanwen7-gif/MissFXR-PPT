CONCEPT 02 / 11

为什么要理解 Token？

它不只是一个技术名词。每次和 AI 对话，背后都在用 Token 衡量三件事：能处理多少、要等多久、要花多少钱。
TOKEN 与哪些使用结果直接相关？
NO. 01

能处理多少内容

模型一次能参考的信息有上限，通常用 Token 数量表示。

NO. 02

要等待多久

需要处理和生成的 Token 越多，通常需要等待更久。

NO. 03

要花多少钱

通过 API 使用模型时，通常按实际 Token 用量计费。

DEFINITION 03 / 11

Token 是什么？用来做什么？

按照什么切分？

分词器按照预先建立的 Token 词表和切分规则处理文字。经常一起出现的字词组合，更可能被保留成一个 Token。

不同模型使用的切分规则和 Token 词表可能不同，所以同一段文字可能得到不同数量的 Token。

CAPACITY 05 / 11

Token 如何影响 AI 的内容容量？

AI 每次回答问题时，不能无限量地同时参考所有聊天记录和文件。它这一次能够参考的信息有一个上限，这个范围就叫“上下文窗口”。

用户上传及 AI 临时取出的相关内容相关资料

所有内容加在一起计算

你的问题、AI 需要参考的前面对话和相关资料，都要先转换成 Token，再判断是否超过上限。

不是简单看聊了几轮、上传了几个文件

真正要看的是：这次实际交给 AI 的内容一共占了多少 Token。

TIME 07 / 11

Token 如何影响 AI 的回答速度？

输入 Token 影响多久开始回答；输出 Token 影响多久生成完整答案。
输入 Token
模型需要先处理你的问题、需要参考的前面对话和资料，然后才能开始回答。
多久开始回答输入越多，通常处理越久
输出 Token
AI 不是先写好完整答案再一次性显示，而是一个 Token 接一个 Token 地生成。
多久生成完成输出越多，通常完成越慢
输入影响“多久开始”｜输出影响“多久完成”

什么时候直接涉及 Token 计费？

公司或开发者把大模型接入自己的产品、网站或工作流程时，通常会通过 API 调用模型。

API 可以简单理解为：让其他产品在后台调用大模型的一种连接方式。

这类调用通常按照实际用量付费，因此会直接统计 Token。

按照实际使用量付费
看不到账单，不代表后台没有 Token 消耗，只是产品没有把底层用量直接展示出来。

COST 09 / 11

API 的 Token 费用怎么算？

一笔 Token 费用，通常需要分别计算输入 Token 和输出 Token。
BASIC FORMULA
费用 ≈ 输入 Token 数 × 输入单价
+ 输出 Token 数 × 输出单价
INPUT TOKEN

输入 Token

这一次交给模型处理的内容，包括当前问题，以及实际带入的前文和资料。

OUTPUT TOKEN

输出 Token

模型这一次生成并返回的内容。

PRICE 10 / 11

为什么同样数量的 Token，费用也可能不同？

最终费用主要取决于：用了多少 Token、使用哪个模型，以及 Token 属于哪种类型。
FACTOR 01

模型不同

不同模型的能力、计算量和产品定价不同，Token 单价也可能不同。

FACTOR 02

类型不同

输入、输出和缓存等 Token 可能采用不同价格。

FACTOR 03

重复输入可以复用

如果能够复用之前的计算结果，这部分输入可能更便宜。

统一报价口径
每 100 万 Token

不代表每次必须使用或购买 100 万 Token

实际费用仍按真实用量计算。

ACTION 11 / 11

理解 Token 后，普通人应该怎么做？

01 / INPUT

管理输入信息

  • 只放当前任务真正需要的背景和资料，删掉无关、重复或互相冲突的信息
  • 资料很多时，按“整理资料—确认结论—生成成品”分阶段推进，每一步留下简短总结
02 / CONTEXT

管理长对话

  • AI 开始漏掉要求、答非所问或前后矛盾时，重新说明当前目标和关键条件
  • 对话很长时，让 AI 整理已确认的信息（handoff 文档），再带着总结开启新对话
03 / OUTPUT

管理输出要求

  • 只需要结论时，直接说明“简短回答，并给出关键依据”
  • 深入分析时，说清问题、背景、判断标准和希望的输出结构
  • 不要只追求更长，先看答案是否真正解决问题
04 / MODEL

按任务选择模型和思考强度

  • 更高档通常意味着更多等待或使用额度，但不一定对所有任务都更好
  • 简单任务先用默认或较低成本方案；先说清目标、资料和输出要求，再用中等模型尝试
  • 到达能力上限时再升级；复杂、高风险任务可直接使用更强方案，重要结果仍要人工核对
